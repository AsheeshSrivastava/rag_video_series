# Evaluation questions

Eleven hand-written questions for the first version. Ten have a known source, labelled by file and section. Question 11 has no answer in the sources, on purpose.
All paths are relative to the frozen sources folder (`prep/sources/`).

| #   | Question                                                                                                         | Source (file and section or page)                                                                                                                                                                    | Expected answer                                                                                                                                                                            | Difficulty |
| --- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| 1   | How do I create a virtual environment in Python?                                                                 | `python-tutorial-3.14/venv.html`, "12.2. Creating Virtual Environments"                                                                                                                              | Run the `venv` module as a script with a folder name, for example `python -m venv tutorial-env`. This creates the folder with a copy of the interpreter.                                   | easy       |
| 2   | Why does my function keep adding to the same list between calls when I wrote `L=[]` as a default argument?       | `python-tutorial-3.14/controlflow.html`, "4.9.1. Default Argument Values"                                                                                                                            | A default value is evaluated only once, when the function is defined. A mutable default such as a list is shared between calls, so it accumulates.                                         | hard       |
| 3   | How do I run clean-up code whether or not an exception happens?                                                  | `python-tutorial-3.14/errors.html`, "8.7. Defining Clean-up Actions"                                                                                                                                 | Put it in a `finally` clause of a `try` statement. It runs last, whether or not an exception was raised.                                                                                   | medium     |
| 4   | What is zero-shot chain-of-thought prompting?                                                                    | `prompt-engineering-guide/pages/techniques/cot.en.mdx`, "Zero-shot COT Prompting"                                                                                                                    | You add a phrase like "Let's think step by step" to the prompt, with no worked examples, so the model reasons before answering.                                                            | easy       |
| 5   | What can I do to defend against prompt injection?                                                                | `prompt-engineering-guide/pages/risks/adversarial.en.mdx`, "Defense Tactics"                                                                                                                         | No easy or widely accepted fix exists. Tactics include adding defence to the instruction, parameterizing prompt components, quoting and formatting inputs, and using a detector.           | medium     |
| 6   | What are the limits of naive RAG?                                                                                | `prompt-engineering-guide/pages/research/rag.en.mdx`, "Naive RAG"                                                                                                                                    | Low precision (misaligned chunks) and low recall (missed chunks). It can also pass outdated information, repeat content, or lean too hard on the retrieved text.                           | medium     |
| 7   | What kinds of failures happen when the answer is in the retrieved context but the model still answers wrongly?   | `pdfs/2401.05856v1.pdf`, page 4, "FP4 Not Extracted" (section 5)                                                                                                                                     | The model fails to pull out the right answer, usually because the context has too much noise or contradictory information.                                                                 | medium     |
| 8   | Can I evaluate a RAG pipeline without human-written reference answers?                                           | `pdfs/2309.15217v2.pdf`, page 1 (Abstract)                                                                                                                                                           | Yes. Ragas is a framework for reference-free evaluation of RAG pipelines, scoring several quality dimensions without ground-truth labels.                                                  | easy       |
| 9   | Which quality scores should I track for RAG, and how does Ragas compute context relevance?                       | `prompt-engineering-guide/pages/research/rag.en.mdx`, "RAG Evaluation" and `pdfs/2309.15217v2.pdf`, page 4                                                                                           | Track context relevance, answer faithfulness and answer relevance. Ragas has an LLM extract the sentences needed to answer, then divides that count by the total sentences in the context. | hard       |
| 10  | If I use program-aided prompting for arithmetic, what number problem should I expect in the Python code it runs? | `prompt-engineering-guide/pages/techniques/pal.en.mdx`, "PAL (Program-Aided Language Models)" and `python-tutorial-3.14/floatingpoint.html`, "15. Floating-Point Arithmetic: Issues and Limitations" | PAL hands the maths to a Python interpreter. Python floats are binary fractions, so most decimal fractions are stored inexactly and results can be slightly off.                           | hard       |
| 11  | How do I deploy my RAG service with Docker or Kubernetes?                                                        | None. Expected answer: "not found".                                                                                                                                                                  | The corpus has no deployment guidance. The system should say it does not know, not invent steps.                                                                                           | medium     |
